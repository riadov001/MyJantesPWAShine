# MyJantes — Guide Utilisateur App Mobile v2

## Pour les clients (Particulier & Professionnel)

---

### Télécharger l'app

L'application MyJantes est disponible sur :
- **App Store** (iPhone/iPad) — rechercher "MyJantes"
- **Google Play** (Android) — rechercher "MyJantes"

---

### Se connecter

Depuis l'écran de connexion, vous pouvez :

**Email + mot de passe**
1. Saisissez votre adresse email
2. Saisissez votre mot de passe
3. Appuyez sur "Se connecter"

**Connexion avec Apple** (iOS uniquement)
1. Appuyez sur "Continuer avec Apple"
2. Authentifiez avec Face ID / Touch ID
3. Vous êtes connecté instantanément

**Connexion avec Google**
1. Appuyez sur "Continuer avec Google"
2. Sélectionnez votre compte Google
3. Vous êtes connecté instantanément

**Mot de passe oublié ?**
- Appuyez sur "Mot de passe oublié"
- Saisissez votre email
- Consultez votre boîte mail et suivez le lien

---

### Créer un compte

1. Appuyez sur "Créer un compte"
2. Choisissez : **Particulier** ou **Professionnel**
3. Remplissez vos informations
4. Pour un compte pro : ajoutez votre raison sociale et SIRET
5. Appuyez sur "S'inscrire"

---

### Tableau de bord (Accueil)

Le tableau de bord affiche en un coup d'œil :
- **Devis en attente** — nombre de devis à valider
- **Factures à payer** — montant total dû
- **Prochain rendez-vous** — date et heure du prochain RDV
- **Solde dû** — total des factures impayées
- **Nos services** — accès rapide aux services disponibles

Tirez l'écran vers le bas pour rafraîchir.

---

### Mes devis

1. Appuyez sur l'onglet **Devis** (📄)
2. La liste affiche tous vos devis avec leur statut :
   - 🟡 **En attente** — en cours d'examen
   - 🟢 **Approuvé** — validé par MyJantes
   - 🟢 **Accepté** — vous avez accepté
   - 🔴 **Refusé**
   - ✅ **Terminé**

3. Appuyez sur un devis pour voir le détail
4. Sur la page de détail, vous pouvez :
   - Consulter les lignes de facturation
   - Voir le montant total
   - Accepter le devis
   - Partager un lien de consultation

---

### Mes factures

1. Appuyez sur l'onglet **Factures** (💳)
2. Consultez vos factures avec leur statut
3. Sur la page de détail :
   - Téléchargez le PDF de la facture
   - **Payez en ligne** avec votre carte bancaire (Stripe)
   - Partagez le lien de la facture

**Paiement en ligne :**
1. Ouvrez la facture
2. Appuyez sur "Payer en ligne"
3. Saisissez vos informations de carte
4. Confirmez le paiement
5. Vous recevez une confirmation par email

---

### Mes rendez-vous

1. Appuyez sur l'onglet **Rendez-vous** (📅)
2. Consultez tous vos rendez-vous
3. Appuyez sur "+ Nouveau" pour réserver

**Prendre un rendez-vous :**
1. Sélectionnez le service souhaité
2. Choisissez un créneau disponible dans le calendrier
3. Renseignez les informations de votre véhicule :
   - Immatriculation
   - Marque et modèle
   - Nombre de jantes et diamètre
4. Ajoutez des notes si besoin
5. Confirmez la réservation

Les créneaux disponibles respectent les horaires d'ouverture de MyJantes (lundi–vendredi) et excluent les jours fériés français.

---

### Messages (Chat)

1. Appuyez sur l'onglet **Messages** (💬)
2. Vos conversations avec l'équipe MyJantes apparaissent ici
3. Ouvrez une conversation pour lire et répondre
4. Vous pouvez joindre des photos en appuyant sur 📎

Le badge rouge sur l'onglet indique le nombre de messages non lus.

---

### Configurateur de jantes

Accéder via le tableau de bord → "Configurateur" :
1. Choisissez le type de prestation (rénovation, personnalisation, polissage…)
2. Sélectionnez la couleur, la finition et la taille
3. Indiquez le nombre de jantes
4. Obtenez une **estimation instantanée**
5. Prenez une photo de vos jantes pour une **analyse IA**
6. Soumettez une demande de devis directement depuis le configurateur

---

### Essai AR (Réalité Augmentée)

Visualisez de nouvelles jantes sur votre voiture avant la pose :
1. Depuis le tableau de bord → "Essai AR"
2. Prenez ou importez une photo de votre véhicule
3. L'IA détecte automatiquement la position des jantes
4. Choisissez une couleur et personnalisez
5. Ajustez la position manuellement avec vos doigts
6. Exportez l'image pour la partager

---

### Avis publics

Après une intervention terminée, vous pouvez laisser un avis :
1. Vous recevez une notification ou un lien par email
2. Donnez une note de 1 à 5 étoiles
3. Ajoutez un commentaire (optionnel)
4. Soumettez — votre avis sera publié après modération

---

### Mon profil

Accédez à votre profil via l'onglet **Profil** (👤) :
- Modifiez vos informations personnelles
- Changez votre photo de profil
- Gérez vos préférences de notifications
- Consultez les CGU et la politique de confidentialité
- Déconnectez-vous

---

### Supprimer mon compte

Pour supprimer définitivement votre compte :
1. Allez dans **Profil** → **Compte**
2. Appuyez sur "Supprimer mon compte"
3. Confirmez dans la boîte de dialogue
4. **Cette action est irréversible.** Toutes vos données sont effacées.

---

### Notifications push

L'app vous envoie des notifications pour :
- Nouveau devis disponible
- Devis approuvé ou refusé
- Facture émise
- Paiement confirmé
- Rendez-vous confirmé ou annulé
- Nouveau message de l'équipe

Pour les gérer : **Profil → Notifications**

---

### Liens publics (sans connexion)

Si vous recevez un lien par email ou SMS (ex. `app.myjantes.fr/public/devis/...`) :
- Ouvrez-le directement — aucun compte requis
- Si vous êtes connecté, vous serez redirigé vers votre espace sécurisé

## Pour les administrateurs & employés

---

### Connexion

Connectez-vous avec vos identifiants admin (email + mot de passe). L'app vous redirige automatiquement vers l'**espace administration** selon votre rôle.

---

### Tableau de bord admin

L'écran d'accueil affiche :
- **CA mensuel** — chiffre d'affaires du mois en cours
- **Prévisionnel** — estimation des revenus à venir
- **Clients** — nombre total de clients inscrits
- **Devis en attente** — à traiter en priorité
- **RDV en attente** — à confirmer
- **Total factures** — nombre de factures émises

Tirez vers le bas pour actualiser. Les chiffres se rafraîchissent automatiquement toutes les 60 secondes.

---

### Gestion des clients

1. Appuyez sur **Clients** (👥)
2. Recherchez un client par nom, email, téléphone ou entreprise
3. Appuyez sur un client pour voir sa fiche :
   - Coordonnées complètes (appel direct, email direct)
   - Type de compte (Particulier / Professionnel)
   - Historique des devis
   - Historique des factures
   - Historique des rendez-vous

---

### Gestion des devis

1. Appuyez sur **Devis** (📄)
2. Filtrez par statut : Tous / En attente / Approuvés / Acceptés / Refusés / Terminés
3. Appuyez sur un devis pour voir le détail :
   - Informations client
   - Lignes de devis avec montants
   - Notes

4. **Changer le statut** :
   - Appuyez sur "Changer le statut"
   - Sélectionnez le nouveau statut dans le menu
   - Confirmez — le client est notifié automatiquement

---

### Gestion des factures

1. Appuyez sur **Factures** (🧾)
2. Le bandeau rouge indique le montant total à encaisser
3. Filtrez par statut : Toutes / En attente / Payées / En retard / Annulées
4. Appuyez sur une facture pour voir le détail :
   - Client, montant HT, TVA, TTC
   - Lignes de facturation détaillées
   - Date d'échéance

5. **Changer le statut** (ex. marquer "Payée" après encaissement espèces) :
   - Appuyez sur "Changer le statut"
   - Sélectionnez "Payée"
   - Confirmez

---

### Gestion de l'agenda

1. Appuyez sur **Agenda** (📅)
2. Le badge rouge indique les rendez-vous à valider
3. Filtrez par statut : Tous / En attente / Confirmés / Terminés / Annulés
4. Les rendez-vous sont triés par date (plus récent en premier)

5. **Confirmer ou annuler un rendez-vous** :
   - Ouvrez la fiche du rendez-vous
   - Consultez : client, service, véhicule, date/heure
   - Appuyez sur "Changer le statut"
   - Sélectionnez "Confirmé" ou "Annulé"
   - Confirmez — le client reçoit une notification

---

### Notifications admin

Recevez des alertes pour chaque événement important :
- Nouveau devis soumis par un client
- Paiement reçu
- Nouveau rendez-vous demandé
- Nouveau message client

---

### Messages (Chat)

L'admin peut lire et répondre aux conversations des clients depuis l'onglet **Chat** dans la section admin.

---

### Mon profil admin

Depuis **Profil** (👤) :
- Modifiez vos informations
- Changez votre photo
- Gérez vos préférences
- Déconnectez-vous

---
