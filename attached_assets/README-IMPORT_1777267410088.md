# MyJantes — Exports prêts à l'import

Trois artefacts sont fournis dans ce dossier et sont **indépendants** : tu peux n'importer que la BDD, ou que les médias, ou les deux.

| Fichier | Taille | Contenu |
|---|---|---|
| `myjantes-db-dump.sql.gz` | ~325 Ko | Dump PostgreSQL complet (schéma + données + 52 tables) |
| `myjantes-media.tar.gz` | ~476 Mo | Tous les fichiers de `uploads/` + `public/uploads/` (603 fichiers) |
| `myjantes-clean.tar.gz` *(racine du projet)* | ~15 Mo | Code source propre prêt à `npm install` |

---

## 1. Importer la base de données

Le dump est généré avec `--clean --if-exists --no-owner --no-privileges` : il **supprime puis recrée** chaque table avant d'insérer les données. Aucune dépendance à un user/role spécifique.

### Cas A — Importer dans une BDD Replit / Neon / locale vide

```bash
# 1. Mettre la chaîne de connexion dans un env var
export TARGET_DB_URL="postgresql://user:pass@host:5432/dbname?sslmode=require"

# 2. Importer
gunzip -c myjantes-db-dump.sql.gz | psql "$TARGET_DB_URL"
```

### Cas B — Importer dans une BDD qui contient déjà des données

⚠️ Le `--clean --if-exists` va **DROP** les tables existantes du même nom. Fais un backup avant si nécessaire :

```bash
pg_dump "$TARGET_DB_URL" | gzip > backup-avant-import.sql.gz
gunzip -c myjantes-db-dump.sql.gz | psql "$TARGET_DB_URL"
```

### Vérification après import

```bash
psql "$TARGET_DB_URL" -c "SELECT COUNT(*) AS users FROM users;"
psql "$TARGET_DB_URL" -c "SELECT COUNT(*) AS invoices FROM invoices;"
psql "$TARGET_DB_URL" -c "SELECT COUNT(*) AS quotes FROM quotes;"
psql "$TARGET_DB_URL" -c "\dt" | head -20
```

## 2. Restaurer les médias

L'archive contient deux dossiers à la racine : `uploads/` et `public/uploads/`. Le second est celui servi en HTTP par Express ; le premier est un répertoire de travail (les deux ont ~95 % de fichiers en commun).

```bash
# Depuis la racine du projet importé
tar -xzf myjantes-media.tar.gz
# Vérification
ls public/uploads | wc -l    # ≈ 301 fichiers
ls uploads | wc -l           # ≈ 304 fichiers
```

⚠️ Ces médias sont des **fichiers locaux uniquement**. Si l'app tourne en production avec Object Storage (R2 / Replit Object Storage), il faut en plus uploader ces mêmes fichiers dans le bucket. Voir `scripts/migrate-uploads-to-cloud.ts` du dossier `myjantes-clean/`.

---

## 3. Workflow complet "from scratch"

```bash
# 1. Décompresser le code propre
tar -xzf myjantes-clean.tar.gz
cd myjantes-clean

# 2. Restaurer les médias
tar -xzf ../myjantes-media.tar.gz

# 3. Installer les dépendances
npm install

# 4. Configurer les secrets
cp .env.example .env
# … remplir DATABASE_URL, SESSION_SECRET, STRIPE_*, etc.

# 5. Importer la base
gunzip -c ../myjantes-db-dump.sql.gz | psql "$DATABASE_URL"

# 6. Lancer
npm run dev
```

---

## 4. Note sur l'Object Storage cloud

Les médias historiques liés aux factures/devis qui ont été uploadés via Cloudflare R2 ou Replit Object Storage **ne sont pas dans cette archive** (c'est du stockage cloud externe). Il faut les exporter séparément :

```bash
# Depuis le projet d'origine
node scripts/migrate_replit_objstore.mjs --export ./object-storage-backup/
```
